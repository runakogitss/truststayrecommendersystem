# TrustStay Full ABSA Windows GPU Rerun

This package refreshes ABSA only. It never rebuilds the 100,111-review sample, MiniLM embeddings, or the frozen 83,686 semantic groups.

The full run was **not executed on this machine**.

## 1. Unzip and open PowerShell

Extract the ZIP beside the existing TrustStay repository. The repository must already contain:

```text
data\frozen_research_sample\
outputs\frozen_research_run\
src\truststay_evidence\
scripts\run_full_absa_refresh.py
```

Open PowerShell in the repository root.

## 2. Create the Windows environment

```powershell
py -3.11 -m venv .venv-full-absa
.\.venv-full-absa\Scripts\Activate.ps1
python -m pip install --upgrade pip
```

## 3. Install CUDA PyTorch, then ABSA dependencies

Install the CUDA-enabled PyTorch command generated for the workstation by the official selector:

<https://pytorch.org/get-started/locally/>

Do this before the generic requirements so the CUDA-specific wheel is not replaced.

```powershell
# Paste the CUDA-enabled command generated by the PyTorch selector here.
python -m pip install -r requirements_full_absa.txt
```

The requirements file includes Transformers, safetensors, SentencePiece, and the repository base dependencies. It intentionally does not pin PyTorch.

## 4. Verify CUDA before running research inference

```powershell
python -c "import torch; print('PyTorch:', torch.__version__); print('CUDA runtime:', torch.version.cuda); print('CUDA available:', torch.cuda.is_available()); print('GPU:', torch.cuda.get_device_name(0) if torch.cuda.is_available() else 'NONE'); print('VRAM GiB:', round(torch.cuda.get_device_properties(0).total_memory/1024**3, 2) if torch.cuda.is_available() else 'NONE')"
```

**FULL RUN SHOULD NOT BEGIN UNLESS `CUDA available: True` IS PRINTED.** The full command requires `--device cuda` and stops instead of falling back to CPU.

## 5. Run the smoke test

The first smoke test may download both Hugging Face models:

- `yangheng/deberta-v3-base-end2end-absa` for aspect extraction and joint sentiment labels;
- `yangheng/deberta-v3-base-absa-v1.1` for low-extraction-score sentiment refinement.

```powershell
python scripts/run_full_absa_refresh.py --smoke-test --device cuda --batch-size 4
```

Inspect the result:

```powershell
type outputs\frozen_research_run_full_absa\smoke_test\FULL_ABSA_VALIDATION.md
type outputs\frozen_research_run_full_absa\smoke_test\ABSA_INFERENCE_PROVENANCE.json
```

The optional hotel lexicon in `configs\full_absa_aspects.yaml` only maps already-extracted raw terms to canonical categories. It never gates inference. A valid zero-aspect review is recorded as `success_no_aspects`, not as a technical failure.

## 6. Run all 100,111 reviews

```powershell
python scripts/run_full_absa_refresh.py --device cuda
```

If CUDA runs out of memory, restart/resume with a smaller batch size:

```powershell
python scripts/run_full_absa_refresh.py --resume --device cuda --batch-size 2
```

Successful completed reviews are not recomputed. No proxy value is used as fallback.

## 7. Validate and locate results

```powershell
python scripts/run_full_absa_refresh.py --validate-only
type outputs\frozen_research_run_full_absa\FULL_ABSA_VALIDATION.md
```

Important outputs:

```text
outputs\frozen_research_run_full_absa\full_absa_predictions.parquet
outputs\frozen_research_run_full_absa\full_absa_aspect_predictions.parquet
outputs\frozen_research_run_full_absa\full_absa_failures.parquet
outputs\frozen_research_run_full_absa\features_full_absa.parquet
outputs\frozen_research_run_full_absa\ABSA_INFERENCE_PROVENANCE.json
outputs\frozen_research_run_full_absa\cluster_invariance_check.json
outputs\frozen_research_run_full_absa\FULL_ABSA_VALIDATION.md
outputs\frozen_research_run_full_absa\SHA256_MANIFEST.csv
```

The child Parquet table preserves one row per extracted aspect, including raw term, character offsets, extractor score, sentiment label, and separate sentiment-model scores where available.

Expected full-run invariant:

```text

MiniLM recomputed: false
```
